## Install-doc findings

Things the upgrade needed that INSTALLATION.md does not say. Fixed in INSTALLATION.md at the end.

- An existing deployment does not get `THEMIS_DASHBOARD_MIGRATE=1` (the installer adds it only when
  it writes a fresh `/etc/themis/dashboard.env`); add it by hand on upgrade.
- There is no "upgrade an existing deployment" section at all: the VM checkout was on a feature
  branch (`feat/attr-gap2-visibility-half`), not `main`, and nothing tells an operator to check.
